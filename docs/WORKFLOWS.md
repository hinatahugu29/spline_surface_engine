# Spline Surface 作業の流れ

目的ごとに、最初から最後までの手順を6例にまとめました。ボタンの意味は [説明書](MANUAL.md)、機能の全体は [機能一覧](FEATURES.md) を見てください。

どの例も、サイドバー（N キー）の **Spline Surface** タブから始めます。座標は x＝車幅方向（中心線が x=0）、y＝前後（前が +y）、z＝上下です。

| 例 | 目的 | 使う機能 |
|---|---|---|
| 1 | 面を1枚から育てて、角を丸める | Add Patch、Extend Edge、Match Edge、Fillet |
| 2 | ボンネットとフェンダーを、プリセットから仕上げる | Presets、Mirror Group、Soft Pull、Check Continuity |
| 3 | 下絵に沿って、カーブから面を張る | Add Blueprint、Line/Arc、Coons、Loft |
| 4 | カーブの網で、1枚のパネルを滑らかに作る | Curve Network、Network Check、Fair Curves |
| 5 | 窓やライトの開口部を作る | Project Curve、Coons、Flange |
| 6 | 仕上げの検査とメッシュ出力 | Check Continuity、Zebra、Panel Gap、To Mesh |

---

## 例 1：面を1枚から育てて、角を丸める

**目的**：1枚のパッチから面を足していき、折れた角を丸める基本の流れをつかむ。

1. **Add Patch** を押す。調整パネルで Shape を「Dome」にすると、ボンネットのような膨らんだ面になる
2. **Extend Edge** を押し、伸ばしたい辺をクリック。ホイールで長さ、C キーで G1/G2 を選び、クリックで確定
3. もう1枚 **Add Patch** で出し、回転して最初の面の辺の近くに置く
4. 2枚を選び（動かしたい方をアクティブに）、**Match Edge** を G0 で実行。辺がそろい、折れた継ぎ目ができる
5. **Fillet** を押し、継ぎ目をクリック → Enter → ホイールで半径 → クリック
6. 丸めた面（つなぎ面）を選ぶと矢印が出る。ドラッグすると後から半径を変えられる

**確認**：Inspect 欄の **Seam Colors** で、継ぎ目が緑（G2）か黄（G1）になっている。

**つまずいたら**：Fillet で継ぎ目が出ないときは、Match Edge（G0）で辺がぴったり重なっているかを確かめる。

## 例 2：ボンネットとフェンダーを、プリセットから仕上げる

**目的**：車体の半分の出発点を置き、反対側を鏡写しにして、形を整える。

1. 3D カーソルを原点に置く（Shift+C）
2. Create 欄の **Hood + Fender** を押す。右半分のボンネットとフェンダーの壁ができ、肩が丸められる。調整パネルで大きさ、クラウン（反り）、肩の半径を変えられる
3. Group 欄で面を選び、**Mirror Group** を押す。反対側が作られ、元と連動する
4. **Soft Pull** で形を整える。面をつかんでドラッグし、Enter で確定。継ぎ目で固定された点は動かないので、つながりは保たれる
5. 面を足したいときは **Extend Edge**（例：ノーズ、カウル）。角には **Corner Fill**、穴には **Fill Hole**
6. Inspect 欄の **Check Continuity** で、全体の継ぎ目を確かめる

**ポイント**：置かれるのはふつうのパッチなので、他の機能がそのまま使える。左右を作り込む前に、右半分だけを仕上げるのがよい（Mirror Group が連動する）。

**サンプル**：`tools/build_sample_hood.py` を Blender で実行すると、ボンネット・フェンダー・ノーズ・カウルをつないだ見本が `samples/hood_fender.blend` にできる。

```bash
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python tools/build_sample_hood.py
```

## 例 3：下絵に沿って、カーブから面を張る

**目的**：側面図に合わせて輪郭のカーブを描き、面にする。

1. Create 欄の **Add Blueprint** で側面の画像を選ぶ。View を Side、Length を車の全長（シーンの単位）にする。地面が z=0、前が +y に置かれる。Opacity で透け具合を調整する
2. 側面から見たとき、下絵の輪郭に沿ってカーブを描く。**Line / Arc** で出して制御点を動かすか、Blender 標準のベジェカーブを使う
3. 正面・上面の下絵も同様に置くと、3方向から合わせられる
4. 面にしたい範囲を囲む3〜4本のカーブを選び、**Coons**（周囲の4辺から面を張る）。断面カーブを並べて通す場合は **Loft**
5. カーブの端がずれて張れないときは、**Snap Ends** で端をくっつける

**ポイント**：カーブは「その時点の形」から面を作る。あとでカーブを動かせば、面は Live Update で付いてくる。下絵は作図の目安で、他の機能には影響しない。

**つまずいたら**：boundary loop is not closed と出たら、カーブの端が離れている。Snap Ends か Gap Tolerance を上げる。

## 例 4：カーブの網で、1枚のパネルを滑らかに作る

**目的**：縦横のカーブを描いて動かすだけで、全体が滑らかなパネルを作る。

1. **Add Curve Grid**（Curve Network の右の＋）で、見本の網を出す。本数・大きさ・膨らみを調整パネルで変える
2. **Network Check** をオンにする。パネルに「ready」と出れば張れる状態。赤い線や印は、交点が足りない・同じ方向のカーブが交差している所
3. カーブの制御点を動かして形を作る。交点ごと動かしたいときは **Move Crossing**、うねりを取りたいときは **Fair Curves**
4. 網のカーブを全部選んで **Curve Network**。区画ごとに面が張られ、内側の継ぎ目は G2 でつながる
5. 以降はカーブを動かせば面が付いてくる

**確認**：**Zebra** をオンにして、縞が継ぎ目で折れていないか見る。

**ポイント**：大きな面を1枚で作るより、網で区画に分けると、局所的な直しが他に響かない。

## 例 5：窓やライトの開口部を作る

**目的**：面に穴を開けず、開口部のまわりを数枚の面で囲んで組む。

1. 外周（パネルの縁）と、開口部の輪郭を描く。すでに面があるなら、輪郭を平らに描いて **Project Curve** で面の上に載せる（Direction は Nearest、または X/Y/Z）
2. 外周の各角と、開口部の対応する角を結ぶ「つなぎ」のカーブを描く。四角い窓なら4本
3. 外周の一辺・開口部の一辺・両側のつなぎ、の4本を選んで **Coons**。これを一辺ずつ、4回行う。つなぎのカーブは隣の面と共有するので、継ぎ目がぴったり合う
4. 窓枠の縁を立ち上げたいときは、開口部の縁に **Flange**（壁を立て、折れ目を丸める）
5. 段が見える継ぎ目は **Match Edge**（G1/G2）で隣の面に合わせる
6. **To Mesh** で1つのメッシュにする

**ポイント**：四角でない開口部（丸いライトなど）は、輪郭を4本の弧に分けて同じ手順にするか、**Fill Hole** の Radial で穴を埋めて外側を囲む。

## 例 6：仕上げの検査とメッシュ出力

**目的**：全体の継ぎ目と見た目を確かめ、問題を直してからメッシュにする。

1. **Check Continuity** を、何も選ばずに押す（表示中の全部の継ぎ目を調べる）。悪い順（open → G0 → G1 → G2）に並ぶ。行の右の矢印ボタンで、その継ぎ目の2枚へ移動できる
2. 問題のある継ぎ目を **Match Edge** や **Soft Pull** で直す。直したら再度 Check Continuity を押す
3. **Seam Colors** をオンにして、全体を見渡す。車の外板なら、全部が緑（G2）に近いのが目標
4. **Zebra** をオンにして、縞が継ぎ目で折れたり、太さが急に変わったりしていないか見る。Stripes（縞の数）、Axis（軸）、Width（明暗の比率）、Soft（縁のぼかし）を変えて、角度を変えて見る
5. **Curvature Comb** で、カーブや面の曲率の包絡線に段差がないか見る
6. パネルの隙間が重要なら **Panel Gap**。Target に隙間の目標値、Tolerance に許容を入れると、外れている所がオレンジで示される
7. Output 欄で Mesh Resolution を決め、全部の面を選んで **To Mesh**。継ぎ目は溶接され、隙間はない。Quads をオンのままにすると、5角形以上の面は四角形と三角形に分けられ、サブディビジョンしても崩れにくい

**メッシュにした後**：メッシュは元のパッチとは切り離されたスナップショット。形を変えたいときはパッチに戻って直し、To Mesh をやり直す。
