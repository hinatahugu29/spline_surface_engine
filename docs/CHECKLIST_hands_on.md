# 手で確かめる項目（v0.73〜v0.86.5）

自動テストは数値（隙間、角度、面の数）を確かめています。ここに並べたのは、**操作の感触と見た目**のように、人が触って見ないと分からない項目です。各項目の「見ること」に当てはまらなかったら、Help パネルの **Copy Bug Report** の内容と一緒に知らせてください。

使うファイル：`samples/hood_fender.blend`（ボンネット）と `samples/body_front_cabin.blend`（車体の前半＋キャビン）。開いたら N キーで Spline Surface タブを出します。

画面に出るボタンの全部は [コマンド一覧](COMMANDS.md) にあります（パネルの順、出る条件つき。確認の列にチェックを付けながら1つずつ押していけます）。ここは、その中でも感触や見た目を見てほしい項目です。

## 1. 既存の操作が変わっていないか（内部を大きく分けたため。最優先）

| 操作 | 見ること |
|---|---|
| 面を足す・Coons・Loft・Extend・Fill Hole・Match Edge をひと通り | エラーが出ない。結果が以前と同じ |
| 元のカーブや面を G で動かす | つながった面がドラッグ中も付いてくる。動きがカクつかない |
| Ctrl+Z／Ctrl+Shift+Z を何度か | 面が消えたり崩れたりしない |
| 保存して開き直す | 開いた後も動かすと付いてくる |

## 2. Even Gap（Inspect → Panel Gap をオン）

`body_front_cabin.blend` で：

| 手順 | 見ること |
|---|---|
| Panel Gap をオン | ドアとフェンダーの間、窓の下とドアの上の間が**緑**の短い線で表示される |
| フェンダー（Fender）を G で前後に少し動かす | ドアの前の縁が付いてきて、隙間が緑のまま |
| ドアを Z 方向に少し動かす | 前の窓（Side_split_split）の下の縁が付いてくる。窓と B ピラーの帯の間が割れない |
| 新しく：2枚のパネルを置き、動かす方をアクティブにして Even Gap | 判断してほしいこと：「アクティブな方が動く」が分かりやすいか。Gap と Flush の既定値は妥当か |

## 3. Split Patch の後の追従（v0.79）

| 手順 | 見ること |
|---|---|
| Match Edge でつないだ面を、つないだ辺を切らない向きで Split | 分けた後も、相手を動かすと付いてくる。切れ目が割れない |
| つないだ辺を切る向きで Split | 「no longer follows (its edge was cut)」の警告が出る |

## 4. Fill Hole の角（v0.78）

`hood_fender.blend` で：

| 手順 | 見ること |
|---|---|
| Zebra をオンにして、ボンネットの前後の角（フェンダーの肩の端）を見る | 肩から斜めに走るひだがない。縞が角を素直に回り込む |
| 後ろの角の下側 | 小さなねじれが残っている（既知。サンプルの閉じるカーブの形による）。気になる程度か |
| 新しく：フィレットで丸めた角の穴を、4本の辺で Fill Hole | 3枚に分かれて埋まる。プレビューと結果が同じ |

## 5. Sweep の Rotate（v0.74）

| 手順 | 見ること |
|---|---|
| 曲がった辺をレールにして Sweep、操作中に R | プレビューで断面がレールに合わせて回る。R でオン／オフが切り替わる |
| レールの面を動かす | Sweep の面が回り方を保ったまま付いてくる |

## 6. Diagnose（Inspect → Diagnose）

| 手順 | 見ること |
|---|---|
| どちらかのサンプルで Diagnose | 一覧が悪い順に並ぶ。行の矢印でその面が選ばれ、画面に収まる |
| Seam Colors をオン（v0.82） | どちらのサンプルでも紫（open）が出ない。分けた Fill の1枚は、接している所だけに線が出る。面を G で動かしたときの色の更新が、以前より遅くない |
| 一覧の中身 | 判断してほしいこと：直し方の案は役に立つか。ドアのタンブルホームのような**意図した形**が「波打ち」として出るのは邪魔か（印を付けて次から出さない機能を検討中） |

## 7. Presets（v0.74）

| 手順 | 見ること |
|---|---|
| Trunk／Roof + Side／Bumper を置く | 出発点として使える形と大きさか。調整パネルの項目（Drop、Wrap など）が分かりやすいか |

## 8. To Mesh（v0.78〜v0.79）

| 手順 | 見ること |
|---|---|
| `body_front_cabin.blend` で全部を選んで To Mesh | 警告に「non_manifold」が出る。編集モードで頂点グループ non_manifold を選ぶと、バンパー上のモールの付け根が選ばれる |
| `hood_fender.blend` で To Mesh | 警告なし。Fill の角に穴がない（編集モードで Select → Select All by Trait → Non Manifold を使うと、選ばれるのが外周だけ） |

## 9. Undo とファイルの開き直し（v0.82.1〜v0.82.3。画面つきのランダム操作で見つけて直したもの）

`body_front_cabin.blend` で：

| 手順 | 見ること |
|---|---|
| File → Open で別のファイルを開き、また `body_front_cabin.blend` を開いて、フェンダーを G で動かす | ドアの前の縁と肩のフィレットが付いてくる（以前は開き直すと、Blender を再起動するまで付いてこなかった） |
| 開いた直後に、サイドバーの Location に値を打ち込んでフェンダーを1回だけ動かす | 1回目から付いてくる |
| Zebra をオン → すぐ Ctrl+Z を何度か | Blender が落ちない・固まらない。隠してある Lip に縞が付かない |
| ドアを選んで Refine → Ctrl+Z 1回 | ドアと反対側のドア（Door_mirror）が両方とも元の点の数に戻る。Ctrl+Shift+Z で両方とも戻る |
| 元になる面（フェンダー、バンパー、ルーフ）を何回か動かしてから、Ctrl+Z を3〜4回 | Follow Arrows（Selected）で、灰色の破線（手で直した扱い）が出ていない。動かすとまた付いてくる |

## 10. カーブ編集（v0.83〜v0.86.4。Curves 欄）

新しいファイルで、Add → Curve → Bezier（点が2つのカーブ）と、Curves 欄の Line／Arc、点の多いカーブ（Bezier を Curve Points で何回かクリック）を用意して確かめます。ボタンの一覧は [コマンド一覧](COMMANDS.md) の「Curves」。

| 手順 | 見ること |
|---|---|
| **Curve Pull** を押し、2点だけのカーブの真ん中をドラッグ | 点が1つ足されて、つかんだ所がマウスに付いてくる。両端は動かない |
| Curve Pull で、途中にある点をドラッグ／Shift+ドラッグ | ドラッグ：その点がマウスに付いてきて周りが曲がる／Shift+ドラッグ：点がカーブに沿って滑る（Curve Points では逆） |
| 点の多いカーブの途中をドラッグ、ホイールで範囲を変える | 範囲がカーブ上に色付きで出る。範囲の外は動かない。曲がり方が自然か。ドラッグ中に重くないか |
| F で減衰の形を切り替えながら引く | 5種類の違いが分かるか |
| E で端の固定を外して、端の近くを引く | 端も付いてくる |
| 平らなカーブで P を押してから引く | カーブが平らなまま曲がる |
| 端の点をドラッグ。面の辺やほかのカーブの近くへ | 吸い付いて、乗ったまま滑る。S で吸着をやめられる |
| X を押してから端の点をドラッグ | 端が X 方向にだけ動く |
| 縦横に交わる網のカーブを引く（Add Curve Grid） | 交わるカーブも付いてきて、網が離れない。N で切り替え |
| カーブの上をクリック／点をドラッグ／点を Ctrl+クリック | 点が足される（形は変わらない）／点がカーブに沿って滑る／点が消えて形はほぼそのまま |
| Ctrl+Z を何回か、最後に Enter（または Esc） | 1回ずつ戻る。Esc では全部取り消し |
| 編集モードで点を選び、右クリック → Slide Points | マウスに合わせて点がカーブに沿って滑る。Shift で細かく |
| 編集モードで Constrained Move（N／T／B／H を切り替え） | 点が自分の向き（曲がる側／カーブに沿って／垂直）に動く。H はハンドルの長さだけ変わる |
| **Point Continuity** をオン、**Curvature Comb** もオン、編集モードで点を G で動かす | 点の色（緑・黄・赤・灰）と櫛が、動かしながら付いてくる |
| **Make G2**（オブジェクトモード、カーブを選んで） | 黄色の点が緑になる。形の変わり方が自然か。直せなかった点の報告が分かりやすいか |
| **Refit Curve**（Tolerance と Count） | 点が減って形がほとんど変わらない。角の点と両端は残る |
| **Attach Curve Ends**：端を、ほかのカーブの端や面の近くに置いてから押す | G1／G2 で滑らかに続く。面には「面に沿う向き」と「面から立ち上がる向き」 |
| 側面図と上面図に平らなカーブを1本ずつ描いて **Two-View Curve** | 両方の図に重なる 3D カーブができる |
| Line で折れ線を作って **Curve Fillet**、平らなカーブで **Offset Curve**、**Extend Curve** | 角が丸くなる／平行なカーブができる／端が伸びる（Natural は曲がり方のまま） |
| 点の多いカーブ3本で **Loft**、4本で **Coons** | すぐに面ができる（v0.86.2 で、点が多いと数十秒かかっていたのを直した） |
| Bridge Edges／Extend／Corner Fill で作った面を選び、G0／G1／G2 の下の **Tension** 欄をドラッグ（v0.86.5） | 面がドラッグに付いて作り直され、継ぎ目は G2 のまま。Ctrl+Z で1回で戻る。重くないか |
| 判断してほしいこと | Curves 欄のボタンの並びと名前は分かりやすいか。Curve Pull の既定の範囲は妥当か |
