# カーブで描いた線から、車のボンネットのような滑らかな曲面を張る。NURBSを知らなくても使えるBlenderアドオンを作りました

カーブモデリングをしていると、こう思う瞬間はないでしょうか。

- 線は思い通りに引けた。でも、その線で囲まれた「面」がうまく張れない
- 面を2枚つなげたら、境目だけ光の反射が折れて見える
- 角を丸めたいだけなのに、周りの面がぐちゃぐちゃになる

車のボディ、バイクのタンク、家電の筐体、ガジェットの外装。こういう「なめらかな曲面」は、見た目では簡単そうなのに、いざ作ると難しいものです。

この記事では、そんな曲面づくりを助けるために作った、Blender 5.x 用のアドオン **Spline Surface** を紹介します。

Blender を普段使っていない方にも読めるように、まず「何が難しいのか」から順番に書きます。

## 滑らかな曲面は、なぜ難しいのか

### 面が「つながっている」のと「滑らかにつながっている」のは別

2枚の面を、境目でぴったり合わせたとします。位置は合っています。でも、そこで面の向きが急に変わっていたら、光を当てると折れ目が見えます。

車の外板で言う「ライン」や「映り込み」は、まさにここで決まります。

CAD の世界では、つなぎ目の滑らかさを3段階で呼び分けます。

- **G0**：位置だけが合っている。折れ目が見える
- **G1**：向きまで合っている。折れ目は消える
- **G2**：曲がり具合まで合っている。映り込みの縞が途切れずにつながる

車の外板が目指すのは G2 です。これを手作業で、一枚ずつ、目で追いながら合わせていくのは、とても骨が折れます。

### 面を作る道具が、もともと「ポリゴン」向き

Blender は、ポリゴン(小さな四角形の集まり)で形を作るのが得意なソフトです。ポリゴンは自由ですが、なめらかな曲面を、数学的に正確な形のまま扱うのは得意ではありません。

一方、Blender には **NURBS サーフェス**という、CAD でよく使われる種類の曲面も入っています。少ない制御点で、なめらかな面を表せる仕組みです。ただ、使いこなすための道具が少なく、普段あまり触られていません。

Spline Surface は、この NURBS サーフェスを土台に、「面を作る、つなぐ、確認する」道具を足したものです。

## Spline Surface でできること

最終的には、普通のメッシュ(ポリゴン)として書き出せます。つまり、そのあとのレンダリングや、他のソフトへの受け渡しは、いつも通りです。

### 線から面を張る

- **Coons**：3〜4本の境界カーブで囲んだ形に、面を張ります
- **Loft**：断面のカーブを並べて、その間を面でつなぎます
- **Curve Network**：縦横に交差するカーブの網から、面を作ります。ボンネットのように、上面図の線と側面図の線から曲面を起こす作り方に向いています
- **Sweep**：ある辺の形を、別の辺に沿って運んで面にします。まっすぐ伸ばして、指定した平面や辺で止めることもできます

カーブは Blender 標準のベジェカーブでよいので、すでにカーブモデリングをしている方は、描いた線をそのまま使えます。

### 面と面を滑らかにつなぐ

- **Extend Edge**：面の辺から、さらに面を伸ばします
- **Bridge Edges**：離れた2つの辺の間を橋渡しします
- **Corner Fill / Fill Hole**：角の隙間や、穴を埋めます
- **Match Edge**：となりの面に合わせて、つなぎ目を G0 / G1 / G2 にそろえます

つなぐときは、G0 / G1 / G2 を選べます。マウスのホイールで、つなぎ方の強さも調整できます。

### 角を丸める、縁を立ち上げる

- **Fillet**：折れている継ぎ目を、半径を決めて丸めます。両側の面が自動で削られ、なめらかな面でつながります。箱の角のように、3つの丸めが出会う場所も、自動で埋めます
- **Flange**：面の縁から壁を立ち上げて、折れ目を丸めます。ドアやボンネットの縁、ホイールアーチの縁取りのような形に使えます。壁の角度や深さは、あとから変更できます

### 作った後から、数値や形を変えられる

ここが、このアドオンでいちばん気を使った部分です。

面は、「どうやって作ったか」を覚えています。だから、元になった面や線を動かすと、そこから作った面が付いてきます(Live Update)。

さらに、面を選ぶと 3D ビューに矢印が出るものがあります。

- 伸ばした面の矢印を引くと、伸ばす長さが変わります
- 丸めた面の矢印を引くと、半径が変わります
- 厚みを付けた面の矢印を引くと、厚みが変わります

「作り直し」ではなく、「つまんで調整」できます。デザインの試行錯誤では、これがとても効きます。

### 滑らかさを、目で確かめる

滑らかに見えるかどうかは、見て確かめるのがいちばんです。

- **Zebra**：縞模様を面に映します。縞が折れていれば、つなぎ目が滑らかではありません
- **Seam Colors**：つなぎ目を、G2 は緑、G1 は黄、G0 は赤で色分けします
- **Curvature Comb / Curvature Map**：曲がり具合を、櫛や色で表示します
- **Check Continuity**：つなぎ目の状態を一覧にして、悪いところから順に並べます

車のデザインやモデリングの現場で、反射の縞を見ながら面を整える、あの作業を Blender の中でやるための道具です。

## 車のボンネットを作る流れ(イメージ)

具体的な流れを、ざっくり書いてみます。

1. 上面図と側面図の下絵を、実寸で立てます(Add Blueprint)
2. 下絵をなぞって、縦横にカーブを引きます
3. Curve Network を押して、カーブの網から曲面を作ります
4. となりのフェンダーを、Extend Edge や Bridge Edges でつなぎます
5. Seam Colors と Zebra で、つなぎ目の滑らかさを確かめます
6. 気になる所は、Soft Pull で面を直接つまんで整えます
7. 縁を Flange で立ち上げて、折れ目を Fillet で丸めます
8. 最後に To Mesh で、ひとつのメッシュにまとめます

左右対称の形は、片側を作ってから Mirror Group で反転できます。

## こんな方に向いています

- Blender でカーブを使ったモデリングをしていて、そこから「面」を張りたい
- Rhino、Alias、Fusion などの CAD に触れたことがあり、Blender でも同じ感覚で曲面を作りたい
- 車やバイク、プロダクトの外装のような、なめらかな面を作りたい
- ポリゴンで面を整えるのに疲れた

逆に、次のような使い方には向いていません。

- キャラクターの顔や体のような、有機的な形をスカルプトで作りたい
- 厳密な寸法を保証する、製造用の CAD データを作りたい(このアドオンの出力はメッシュです)

## 対応環境と注意点

- 対象は **Blender 5.x** です
- 面は NURBS サーフェスで作り、出力はメッシュです
- 手で形を直した面は、「手で直した」と記録され、Live Update で勝手に上書きされません
- 実際の作業での検証を進めている段階です。不具合を見つけたときは、アドオン内の「Copy Bug Report」で状況をコピーして、教えてもらえると助かります
