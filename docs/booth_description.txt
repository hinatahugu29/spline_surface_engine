【キャッチコピー】

【一覧用の短い説明(検索結果に出る分)】
Blender 5.x 用の無料アドオンです。カーブから面を張り、面どうしを滑らかにつなぎ、縞模様で確かめて、最後にメッシュにできます。車・バイク・家電の外装づくりに。


■ このアドオンについて
Spline Surface は、車のボディのような「どこから見ても滑らかにつながった曲面」を、Blender の中で作るためのアドオンです。

ふつう、こうした曲面を作るには、制御点の並びや、面のつなぎ方(G1・G2)といった CAD 寄りの知識が要ります。このアドオンは、それをボタンとクリックの操作にまとめました。

面そのものは、Blender 標準の NURBS サーフェスです。アドオンを外しても、作った面はそのまま残ります。


■ できること
・面をつなぐ
  隣り合う面を、位置だけ(G0)、向きまで(G1)、曲がり具合まで(G2)そろえてつなげます。
  面を伸ばす、離れた辺の間を橋渡しする、角の隙間や穴を埋める、折れた角を丸める(フィレット)、辺から壁を立ち上げる(フランジ)など。

・カーブから面を張る
  3〜4本のカーブで囲んで面にする(Coons)、断面を並べて通す(Loft)、縦横のカーブの網から全体を一度に張る(Curve Network)。

・車体パネルの出発点を置く
  ボンネット、ルーフ、ドア、ボンネット+フェンダーの形を1ボタンで置けます。

・下絵を実寸で置く
  側面・正面・上面の画像を、車の寸法に合わせて立てます。

・元を動かすと、あとから追従する
  面は「何から、どう作ったか」を記録しています。元の面やカーブを動かすと、それに依存する面が自動で作り直されます(Live Update)。左右対称のコピーも連動します。

・滑らかさを確かめる
  継ぎ目の色分け(G2 緑・G1 黄・G0 赤)、縞模様の映り込み(ゼブラ)、曲率の櫛と色分け、継ぎ目の一覧(悪い順に並び、クリックで該当の面へ移動)、パネルの隙間の測定。

・形を整える
  面をつかんで周りをなめらかに引っぱる(Soft Pull)、うねりを取る、制御点を増やす、ラティスで大きく変形する。継ぎ目の滑らかさは保たれます。

・メッシュにして出力する
  面を1つのメッシュに溶接します。継ぎ目に隙間は出ません。四角形中心で出力でき、サブディビジョンにも向きます。


■ 向いている使い方
・車・バイク・家電・プロダクトの外装のような、なめらかな面の組み合わせ
・断面や輪郭のカーブを先に描いて、そこから面を張っていく作り方
・「この継ぎ目は G2 でつながっているか」を確かめながら作り込む作業


■ 向いていないこと・できないこと
・有機的な形のスカルプトや、細かい彫り込み
・面の上での切り抜き(トリム)。窓やライトの開口部は、別々の面で囲んで組む方法を説明書で紹介しています
・IGES / STEP などの NURBS の書き出し。出力は Blender のサーフェスとメッシュです


■ 動作環境
・Blender 5.0 以降(5.2 で動作確認)
・Windows で開発・確認しています。Mac / Linux では確認していません

■ インストール方法
1. Blender の「編集 → プリファレンス → アドオン」を開く
2. 右上のメニューから「ディスクからインストール」を選び、ZIP ファイルを指定する(ZIP は解凍せず、そのまま選びます)
3. 3D ビューで N キーを押してサイドバーを開くと、「Spline Surface」タブが出ます

新しいバージョンに入れ替えるときも、同じ手順で ZIP を選び直してください。


■ はじめかた
作業の流れ(同梱の文書)に、次の6例を載せています。
1. 面を1枚から育てて、角を丸める
2. ボンネットとフェンダーを、プリセットから仕上げる
3. 下絵に沿って、カーブから面を張る
4. カーブの網で、1枚のパネルを滑らかに作る
5. 窓やライトの開口部を作る
6. 仕上げの検査とメッシュ出力
