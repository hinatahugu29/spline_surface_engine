# Spline Surface 機能一覧

対象バージョン：0.50 ／ Blender 5.0 以降（5.2 で動作確認）

機能を目的別に並べた一覧です。使い方の詳細は [説明書](MANUAL.md)、手順は [作業の流れ](WORKFLOWS.md) を見てください。

**検証の列の読み方**
- **自動**：Blender をヘッドレスで動かすテスト（`tests/test_blender.py`）と、計算部分の単体テスト（`tests/test_core.py`）で、結果の数値まで確かめています
- **要実機**：自動テストでは操作の中身（計算・作られる面）までは確かめていますが、3D ビューでのクリック、ホイール、描画の見え方は、実際の画面で触って確かめる必要があります

---

## 1. 作る（Create 欄）

| 機能 | 何ができるか | 元になるもの | 検証 |
|---|---|---|---|
| Add Patch | 平面・円弧・ドームのパッチを1枚出す | 3D カーソル | 自動 |
| Body panel presets | Hood / Roof / Door / Hood + Fender の出発点の形 | 3D カーソル | 自動 |
| Add Blueprint | 側面・正面・上面の下絵を実寸で置く | 画像ファイル | 自動（見え方は要実機） |
| Line / Arc | 境界に使いやすい直線・厳密な円弧のベジェ | 3D カーソル | 自動 |
| Coons | 3〜4本の境界カーブで囲まれた面 | カーブ3〜4本 | 自動 |
| Loft | 断面カーブを順に通る面 | カーブ2本以上 | 自動 |
| Curve Network | 縦横に交差するカーブの網から、区画ごとの面（内側の継ぎ目は G2） | カーブの網 | 自動 |
| Add Curve Grid | 見本の網を出す | なし | 自動 |
| Network Check | 網の読み取り結果を色で表示 | カーブの網 | 要実機 |
| Move Crossing / Fair Curves | 網の交点ごとの移動、カーブのうねり取り | ベジェカーブ | 自動（ドラッグは要実機） |
| Project Curve | カーブを面の上に載せる（最短・軸方向・視線方向） | カーブ＋パッチ | 自動 |
| Trim to Mesh（試作） | 閉じたカーブで穴を開けたメッシュを作る。**試作のまま** | パッチ＋閉カーブ | 自動 |
| Snap Ends / Gap Tolerance | カーブの端をくっつける、「ついている」とみなす距離 | カーブ | 自動 |
| Regenerate | 面をレシピから作り直す | パッチ | 自動 |
| Copy Bug Report | バージョン・設定・選んだ面のレシピと継ぎ目をクリップボードへ（不具合報告用） | 面 | 自動（コピー自体は要実機） |

## 2. 伸ばす・つなぐ（Grow & Connect 欄）

| 機能 | 何ができるか | 継続性 | 検証 |
|---|---|---|---|
| Extend Edge | 開いた辺から面を伸ばす | G1 / G2 | 自動／要実機 |
| Bridge Edges | 離れた2辺（辺とカーブ）の間を橋渡しする | G0 / G1 / G2 | 自動／要実機 |
| Match Edge | 辺を隣の面の辺に合わせる | G0 / G1 / G2 | 自動 |
| Corner Fill | 角の V 字の隙間を埋める | G1 / G2 | 自動／要実機 |
| Fill Hole | 辺とカーブで囲まれた穴を埋める（4辺は1枚、それ以外は中心で分割） | G0 / G1 / G2 | 自動／要実機 |
| Fillet | 折れた継ぎ目を半径で丸める。後から矢印で半径を変えられる | G1 / G2 | 自動／要実機 |
| Flange | 辺から壁（縁の折り返し）を立ち上げ、折れ目を丸める | G1 / G2 | 自動／要実機 |
| Split Patch | 面を等パラメータ線で2枚に分ける | G2 | 自動／要実機 |
| Offset Surface | 面を法線方向にずらしたコピー（板厚・内側の面） | 元と連動 | 自動 |

## 3. まとめて扱う（Group 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| Live Update | 元の面・カーブを動かすと、依存する面が自動で作り直される | 自動 |
| Linked Edit（Falloff） | 面を編集したとき、周りの面も付いてくる | 自動 |
| Edge Chain | つながった開いた辺を1本のカーブにまとめる | 自動／要実機 |
| Merge | 格子状に並んだ面を1枚に作り直す（近似） | 自動 |
| Select / Regenerate Group | つながった面をまとめて選ぶ／作り直す | 自動 |
| Mirror Group | 面を対称面で反転コピーし、連動させる。Scope で対象（Group／Selected／Selected + Built From Them）を選べる | 自動 |
| Cage（Add / Apply / Remove） | ラティスで面のグループを大きく変形する | 自動 |

## 4. 形を整える（Shape 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| Soft Pull | 面・線・制御点をつかんで、周りをなめらかに引く。継ぎ目の固定点は動かさない | 自動（操作は要実機） |
| Control Mesh / Done | 制御点をメッシュにして編集モードで動かし、戻す | 自動 |
| Fair | 内側のうねりを取る | 自動 |
| Refine | 形を変えずに制御点を増やす（全区間を2分割） | 自動 |
| Add Row U / V | 制御点を1行（列）だけ足す。編集モードでも使える。1区間なら厳密、それ以外は形がわずかに動く | 自動 |

## 5. 確かめる（Inspect 欄）

| 機能 | 何がわかるか | 検証 |
|---|---|---|
| Check Continuity | 継ぎ目ごとの G0/G1/G2、隙間・角度・曲率の差。悪い順に並び、行から該当の面へ移動 | 自動 |
| Zebra | 縞模様の映り込み（縞の数・軸・明暗の比率・縁のぼかしを調整） | 自動（見え方は要実機） |
| Seam Colors | 全部の継ぎ目を G2＝緑・G1＝黄・G0＝赤・離れている＝紫で表示 | 要実機 |
| Curvature Comb | 曲率の櫛。包絡線の段差やうねりを見る | 要実機 |
| Curvature Map | 曲率による色分け（Gaussian / Mean） | 要実機 |
| Control Points | 固定された点／自由な点の色分け | 要実機 |
| Panel Gap | 向かい合うパネルの隙間と段差を目標値と比べる | 自動（表示は要実機） |

## 6. 出力する（Output 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| To Mesh | 面を溶接した1つのメッシュにする。継ぎ目は隙間なし、Quads で5角形以上の面を四角形・三角形に分ける | 自動 |
| Mesh Resolution | 一番長い辺の分割数 | 自動 |

## 7. 自動で働くしくみ

| しくみ | 内容 |
|---|---|
| レシピ | 面ごとに「何から、どう作ったか」を記録（カスタムプロパティ `spline_surface`） |
| 依存グラフ | レシピから、どの面がどの面に依存するかを組み立てる。Live Update の順序づけに使う |
| 手で直した面の保護 | 制御点を手で動かした面は、自動の作り直しで上書きしない |
| 固定された点 | 継ぎ目の G0/G1/G2 に応じて、辺から1/2/3列の制御点を編集から守る |
| ギズモ（矢印） | Extend / Offset / Fillet で作った面の長さ・距離・半径を後から変える |

---

## 8. 対応していないこと

| 項目 | 状況 |
|---|---|
| 面の上での穴あけ（トリム） | 作らない方針。開口部は別々のパッチで囲んで組む（作例 C）。Trim to Mesh は試作のメッシュ出力のみ |
| 本物の NURBS 書き出し（IGES / STEP） | 未対応。出力は Blender のサーフェスとメッシュ |
| 4辺以外の Fill Hole の G2 | 中心点の付近で最大1°程度ずれる |
| Fillet の切り詰め量 | 継ぎ目全体で一定 |
| Panel Gap の「隙間をそろえる」操作 | 測って色で示すだけ。自動でそろえる操作はない |
