# Spline Surface 機能一覧

対象バージョン：0.86.3 ／ Blender 5.0 以降（5.3 で動作確認）

機能を目的別に並べた一覧です。使い方の詳細は [説明書](MANUAL.md)、手順は [作業の流れ](WORKFLOWS.md)、画面に出るボタンの全部は [コマンド一覧](COMMANDS.md) を見てください。

**検証の列の読み方**
- **自動**：Blender をヘッドレスで動かすテスト（`tests/test_blender.py`）と、計算部分の単体テスト（`tests/test_core.py`）で、結果の数値まで確かめています。2つのサンプルは、開いて全部を作り直し、継ぎ目の角度とメッシュの穴まで確かめています（`tests/test_sample.py`、`tests/test_body.py`）。Live Update と Undo／Redo の組み合わせ、ファイルの開き直し、クリックで選ぶツール（Fillet・Flange・Fill Hole）の操作は、Blender の画面を開いて動かすテスト（`tests/test_gui.py`、`tests/test_gui_modal.py`）でも確かめています。まとめては `py tools/run_tests.py`
- **要実機**：自動テストでは操作の中身（計算・作られる面）までは確かめていますが、3D ビューでのクリック、ホイール、描画の見え方は、実際の画面で触って確かめる必要があります

## 1.5 カーブを編集する（Curves 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| Curve Points | クリックで点を足す（形は不変）、点をドラッグしてカーブに沿って滑らせる、Ctrl+クリックで点を消す（前後の向きを保って合わせ直す） | 自動（計算・画面テスト） |
| Curve Pull（専用のボタン。Curve Points と同じ道具） | カーブ上のどこでもつかんで引く（近くに動かせる点がなければ、つかんだ所に点を足してから）。範囲はカーブに沿った長さ、減衰5種、端の固定、網の交わるカーブも付いてくる、画面／カーブの平面／軸の向き | 自動（計算・画面テスト） |
| Slide Points（編集モード） | 選んだ点をカーブに沿って滑らせる | 自動（計算・画面テスト） |
| Dissolve Points（編集モード） | 選んだ点を消して形を保つように合わせ直す | 自動 |
| Constrained Move（編集モード） | 点自身の接線・法線・垂直の向きに動かす、ハンドルの長さだけ変える、G2 を保つ | 自動（計算・画面テスト） |
| Make G2 | ハンドルの長さだけで曲率をそろえる（全部の点をまとめて解く。角・変曲点・片側がまっすぐな点は報告） | 自動 |
| Refit Curve | 形を保って点を減らす（許容誤差 % か点の数。角と両端は残る） | 自動 |
| Attach Curve Ends | 端をほかのカーブの端（G0/G1/G2 で続ける）・面（面の上へ、面に沿う向き／面から立ち上がる向き）・カーブの途中へ付ける | 自動 |
| 端の吸着（Curve Points の中） | 端の点をドラッグすると、面の辺やカーブに吸い付いて乗ったまま滑る | 自動（画面テスト） |
| Point Continuity | カーブの点をつながり方で色分け（G2 緑・G1 黄・角 赤・端 灰）、編集中も追従 | 自動（計算） |
| Two-View Curve | 2方向の図の平らなカーブ2本から 3D カーブ | 自動 |
| Curve Fillet | 角の点を半径で丸める（G1、切り詰めは正確） | 自動 |
| Offset Curve | 平らなカーブを平面内で平行にずらしたコピー（角は丸くつなぐ） | 自動 |
| Extend Curve | 端を伸ばす（Natural：曲がり方のまま、Straight：まっすぐ） | 自動 |

## 2. 伸ばす・つなぐ（Grow & Connect 欄）

| 機能 | 何ができるか | 継続性 | 検証 |
|---|---|---|---|
| Extend Edge | 開いた辺から面を伸ばす | G1 / G2 | 自動／要実機 |
| Bridge Edges | 離れた2辺（辺とカーブ）の間を橋渡しする | G0 / G1 / G2 | 自動／要実機 |
| Match Edge | 辺を隣の面の辺に合わせる。以後その面に追従する（大きく動かしても切れない）。Spread で面全体をなだらかに動かす。追従の一覧から連続性の変更・解除 | G0 / G1 / G2 | 自動 |
| Corner Fill | 角の V 字の隙間を埋める | G1 / G2 | 自動／要実機 |
| Fill Hole | 辺とカーブで囲まれた穴を埋める（4辺は1枚、それ以外は中心で分割。まっすぐ続く辺は1辺として、本当の角の数で埋める） | G0 / G1 / G2 | 自動／要実機 |
| Fillet | 折れた継ぎ目を半径で丸める。後から矢印で半径を変えられる | G1 / G2 | 自動／要実機 |
| Align Normals | 辺を共有する面どうしの向き（法線）をそろえる | - | 自動／要実機 |
| Sweep | 断面の辺を、別の辺（レール）に沿って運んで面にする（Straight の長さは Auto／手入力／辺・平面への Target。Rotate で断面をレールに合わせて回す） | G0（継ぎ目） | 自動／要実機 |
| Flange | 辺から壁（縁の折り返し）を立ち上げ、折れ目を丸める。Edit で角度・深さを後から変えられる | G1 / G2 | 自動／要実機 |
| Split Patch | 面を等パラメータ線で2枚に分ける。Match Edge・Even Gap の指定は、その辺を持つ片へ引き継ぐ | G2 | 自動／要実機 |
| Duplicate Edge as Curve | 面の辺・等パラメータ線をベジェカーブとして複製（Shift+クリックで複数）。Coons などの境界に使える | 線そのもの（次数3以下で誤差 0） | 自動 |
| Offset Surface | 面を法線方向にずらしたコピー（板厚・内側の面） | 元と連動 | 自動 |

## 3. まとめて扱う（Group 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| Live Update | 元の面・カーブを動かすと、依存する面が自動で作り直される。アドオンの操作は、作り直した面まで含めて Ctrl+Z 1回で戻る | 自動（Undo／Redo、ファイルの開き直しを含む） |
| Use This Scene's Copies | シーンを複製したとき、複製した面をそのシーンの複製に付け直す | 自動 |
| Follow Arrows／List Links | どの面がどれに追従しているかを矢印と一覧で表示（追従中・手で編集・失敗・元が消えた、を色分け） | 自動（描画の見え方は要実機） |
| Linked Edit（Falloff） | 面を編集したとき、周りの面も付いてくる | 自動 |
| Edge Chain | つながった開いた辺を1本のカーブにまとめる | 自動／要実機 |
| Merge | 格子状に並んだ面を1枚に作り直す（近似） | 自動 |
| Select / Regenerate Group | つながった面をまとめて選ぶ／作り直す | 自動 |
| Unlink / Remove Mirror | 鏡側を元から切り離す／鏡側を消す | 自動 |
| Mirror Group | 面を対称面で反転コピーし、連動させる。Scope で対象（Group／Selected／Selected + Built From Them）を選べる | 自動 |
| Cage（Add / Apply / Remove） | ラティスで面のグループを大きく変形する | 自動 |

## 4. 形を整える（Shape 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| Soft Pull | 面・線・制御点をつかんで、周りをなめらかに引く。継ぎ目の固定点は動かさない | 自動（操作は要実機） |
| Control Mesh / Done | 制御点をメッシュにして編集モードで動かし、戻す | 自動 |
| Fair | 内側のうねりを取る | 自動 |
| Origin to Center | 面の原点を制御点の中心へ移す（面は動かない。作り直しても保たれる） | 自動 |
| Refine | 形を変えずに制御点を増やす（全区間を2分割） | 自動 |
| Add Row U / V | 制御点を1行（列）だけ足す。編集モードでも使える。1区間なら厳密、それ以外は形がわずかに動く | 自動 |

## 5. 確かめる（Inspect 欄）

| 機能 | 何がわかるか | 検証 |
|---|---|---|
| Check Continuity | 継ぎ目ごとの G0/G1/G2、隙間・角度・曲率の差（辺の一部だけで接する継ぎ目も）。悪い順に並び、行から該当の面へ移動 | 自動 |
| Diagnose | レシピより弱い継ぎ目、指定のない折れ、面の波打ち（曲率の符号の変化・余分な山）を、直し方の案つきで悪い順に。意図した形には印を付けて次から出さない | 自動 |
| Zebra | 縞模様の映り込み（縞の数・軸・明暗の比率・縁のぼかしを調整）。オンの間にアドオンの操作で作った面にも付く | 自動（見え方は要実機） |
| Seam Colors | 全部の継ぎ目を G2＝緑・G1＝黄・G0＝赤・離れている＝紫で表示（辺の一部だけの継ぎ目も。わざと離れている所は除く） | 要実機 |
| Curvature Comb | 曲率の櫛。包絡線の段差やうねりを見る | 要実機 |
| Curvature Map | 曲率による色分け（Gaussian / Mean） | 要実機 |
| Control Points | 固定された点／自由な点の色分け | 要実機 |
| Panel Gap | 向かい合うパネルの隙間と段差を目標値と比べる | 自動（表示は要実機） |
| Even Gap | アクティブなパネルの辺を動かして隙間を目標値にそろえ、段差をなくす。相手が動いても保つ | 自動 |

## 6. 出力する（Output 欄）

| 機能 | 何ができるか | 検証 |
|---|---|---|
| To Mesh | 面を溶接した1つのメッシュにする。継ぎ目は隙間なし、Quads で5角形以上の面を四角形・三角形に分ける。3枚以上の面が付く辺は警告し、頂点グループ non_manifold に入れる | 自動 |
| Mesh Resolution | 一番長い辺の分割数 | 自動 |
| Curve Detail | 曲がり90°あたりの最低分割数（小さい丸みを角ばらせない） | 自動 |

## 7. 自動で働くしくみ

| しくみ | 内容 |
|---|---|
| レシピ | 面ごとに「何から、どう作ったか」を記録（カスタムプロパティ `spline_surface`） |
| 依存グラフ | レシピから、どの面がどの面に依存するかを組み立てる。Live Update の順序づけに使う |
| 手で直した面の保護 | 制御点を手で動かした面は、自動の作り直しで上書きしない（その面を元にしている面は、手で直した形に付いていく） |
| 固定された点 | 継ぎ目の G0/G1/G2 に応じて、辺から1/2/3列の制御点を編集から守る |
| ギズモ（矢印） | Extend / Offset / Fillet で作った面の長さ・距離・半径を後から変える |

## 8. 対応していないこと

| 項目 | 状況 |
|---|---|
| 面の上での穴あけ（トリム） | 作らない方針。開口部は別々のパッチで囲んで組む（作例 C）。Trim to Mesh は試作のメッシュ出力のみ |
| 本物の NURBS 書き出し（IGES / STEP） | 未対応。出力は Blender のサーフェスとメッシュ |
| 4辺以外の Fill Hole の G2 | 中心で面どうしは G1（v0.81 から）。曲率（G2）は中心の付近で合わない |
| Fillet の切り詰め量 | 継ぎ目全体で一定 |
| Fill Hole の角の G2 | 角の付近は向き（G1）まで。曲率（G2）はそろわない |
| To Mesh で3枚以上が付く辺 | 1枚の面としてつながらない（印を付けるだけ。別のメッシュに分ける選択肢は未対応） |
