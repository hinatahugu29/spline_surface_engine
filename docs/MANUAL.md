# Spline Surface 説明書

対象バージョン：0.40 ／ Blender 5.0 以降

---

## 1. どんなアドオンか

**Spline Surface** は、車のボディのような「どこから見ても滑らかにつながった曲面」を、NURBS の専門知識がなくても作れるようにする Blender 用のアドオンです。

ふつう、こうした曲面を作るには、制御点の並びやノット、面と面のつなぎ方（G1・G2）といった CAD 寄りの知識が要ります。このアドオンでは、それをボタンとクリックの操作にまとめています。

- **面を「つなぐ」ことに強い**：隣り合う面を、位置だけ（G0）、向きまで（G1）、曲がり具合まで（G2）そろえてつなげます。継ぎ目の滑らかさは色や縞模様で確かめられます
- **作り方を覚えている**：面はそれぞれ「何から、どう作ったか（レシピ）」を記録しています。元の面やカーブを動かすと、それに依存する面が自動で作り直されます（Live Update）
- **最後はメッシュにする**：形が決まったら To Mesh で1つのメッシュに溶接して、モデリングやレンダリングに使います

面そのものは Blender 標準の NURBS サーフェスです。アドオンを外しても、作った面はそのまま残ります。

### 向いていること
- 車・バイク・家電・プロダクトの外装のような、なめらかな面の組み合わせ
- 断面や輪郭のカーブを先に描いて、そこから面を張っていく作り方
- 「この継ぎ目は G2 でつながっているか」を確かめながら作り込む作業

### 向いていないこと
- 窓やライトのような開口部の切り抜き（面の上でのブール処理）は、まだできません
- 有機的な形のスカルプトや、細かいディテールの彫り込み

## 2. 動作環境とインストール

- Blender 5.0 以降（5.2 で動作確認）
- 配布物：`spline_surface-x.y.z.zip`

**インストール手順**

1. Blender の「編集 → プリファレンス → アドオン」を開く
2. 右上のメニューから「ディスクからインストール」を選び、ZIP ファイルを指定する
3. 3D ビューで N キーを押してサイドバーを開くと、**Spline Surface** タブが出ます

新しいバージョンに入れ替えるときも、同じ手順で ZIP を選び直してください。

## 3. 基本の考え方

### パッチ（面）と辺の名前
アドオンが扱う面1枚を **パッチ** と呼びます。パッチは縦横の格子状に並んだ制御点で形が決まり、縦方向を **U**、横方向を **V** と呼びます。

パッチには4本の辺があり、次の名前で呼びます。辺を選ぶ操作では、マウスを近づけるとこの名前が表示されます。

| 辺 | 場所 |
|---|---|
| U0（U min） | U の始まり側の辺 |
| U1（U max） | U の終わり側の辺 |
| V0（V min） | V の始まり側の辺 |
| V1（V max） | V の終わり側の辺 |

### 継続性（G0 / G1 / G2）
2枚の面が接する所（継ぎ目）が、どれくらい滑らかにつながっているかを表します。

| 記号 | 意味 | 見え方 |
|---|---|---|
| **G0** | 位置だけつながっている | 折れ目が見える |
| **G1** | 向き（接する平面）までそろっている | 折れ目はないが、映り込みの太さが継ぎ目で変わる |
| **G2** | 曲がり具合（曲率）までそろっている | 映り込みが継ぎ目を意識させずに流れる。車の外板の目標 |

### レシピと Live Update
アドオンで作った面は、「どの面のどの辺から、どう作ったか」を **レシピ** として覚えています。

- 元にした面やカーブを動かすと、その面から作られた面が自動で作り直されます。これを **Live Update** と呼びます（Group 欄のチェックでオン／オフ）
- **Regenerate** ボタンで、いつでもレシピから作り直せます

### 手で直した面
アドオンが作った面を、編集モードで制御点を動かしたり、G キーで移動したりすると、その面は **「手で直した面」** として記録されます。手で直した面は、Live Update や Regenerate で上書きされません。手の修正を消したくない場合はそのままにし、レシピの形に戻したい場合は Regenerate を押してください（警告が出ます。Ctrl+Z で戻せます）。

### 固定された点（ロック）
面の内側を整える機能（Soft Pull・Fair・Control Mesh など）では、継ぎ目の滑らかさを守るため、継ぎ目に近い制御点を動かしません。

| 継ぎ目 | 固定される列 |
|---|---|
| G0 | 辺の上の1列 |
| G1 | 辺から2列 |
| G2 | 辺から3列 |

Inspect 欄の **Control Points** で、固定された点（オレンジ）と自由に動かせる点（水色）を確かめられます。

### 対応している面
- NURBS サーフェスで、Endpoint がオン、Cyclic がオフ、制御点の Weight がすべて 1 のもの
- アドオンの Add Patch などで作った面は、すべてこの条件を満たします

## 4. はじめての作例

### 作例 A：面をつないで角を丸める

1. **面を出す**：Create 欄の **Add Patch** を押す。左下の調整パネルで Shape を「Dome」にすると、ボンネットのような面になります
2. **伸ばす**：Grow & Connect 欄の **Extend Edge** を押し、3D ビューで伸ばしたい辺をクリック。ホイールで長さ、C キーで G1/G2 を選べます
3. **別の面を角度をつけて置く**：もう1枚 Add Patch で面を出し、回転させて最初の面の辺の近くに置く
4. **辺をぴったり合わせる**：2枚を選び（合わせたい側をアクティブに）、**Match Edge** を「G0」で実行。辺の位置だけがそろい、折れた継ぎ目ができます
5. **角を丸める**：**Fillet** を押し、その継ぎ目をクリック → Enter → ホイールで半径を決めてクリック。両側の面が切り詰められ、丸いつなぎ面が入ります
6. **確かめる**：Inspect 欄の **Seam Colors** と **Zebra** で、継ぎ目が緑（G2）で、縞模様が途切れていないかを見ます
7. **メッシュにする**：全部の面を選び、Output 欄の **To Mesh** を押します

### 作例 B：カーブの網から面を張る

1. Create 欄の **Curve Network** の右にある **＋**（Add Curve Grid）を押す。縦横に交差したカーブの網が出ます
2. **Network Check** をオンにする。網がどう見えているかが色で表示され、パネルに「ready」と出れば面を張れる状態です
3. カーブの制御点を動かして形を作る。交点ごと動かしたいときは **Move Crossing**、カーブのうねりを取りたいときは **Fair Curves** を使います
4. 網のカーブを全部選んで **Curve Network** を押す。区画ごとに面が張られ、内側の継ぎ目は G2 でつながります
5. 以降は、カーブを動かせば面が付いてきます（Live Update）

## 5. パネルごとの機能説明

サイドバーの Spline Surface タブは、上から次の欄に分かれています。

### 5.1 Create（作る）

| 機能 | 内容 |
|---|---|
| **Add Patch** | 3D カーソルの位置にパッチを出します。Shape（Plane＝平ら / Arc＝一方向に曲がる / Dome＝二方向に曲がる）、大きさ、Bulge（膨らみの高さ）、制御点の数、Order（次数＋1）を調整パネルで変えられます |
| **Add Blueprint** | 下絵の画像（側面・正面・上面）を、実寸で立てて置きます。ファイルを選び、View と Length（側面・上面では車の全長、正面では車幅）を決めます。下絵は Blender の画像エンプティになり、地面が z=0、車の中心線が x=0、車の前が +y になるように置かれます（側面・正面は下辺の中央、上面は中央が原点）。Offset で位置をずらし、Opacity で透け具合、Mirror で左右反転ができます。作図の目安として使い、ほかの機能には影響しません |
| **Body panel presets**（Hood／Roof／Door／Hood + Fender） | 3D カーソルの位置に、車体パネルの出発点になる形を置きます。座標は x＝車幅方向（中心線が x=0）、y＝前後、z＝上下。Hood と Roof は上に反った（クラウン付きの）パネル、Door は外へふくらんで上が内に倒れた縦のパネル。**Hood + Fender** は右半分のボンネットとフェンダーの壁を作り、肩を Fillet で丸めます（Mirror Group で反対側へ）。大きさ・クラウン・肩の半径は調整パネルで変えられます。置かれるのはふつうのパッチなので、Soft Pull や Extend などでそのまま整えられます |
| **Line** | 3D カーソルの位置に、境界として使いやすい直線をベジェで追加します（Add Boundary Curve、Shape=Line）。調整パネルで Length を変えられます |
| **Arc** | 3D カーソルの位置に、境界として使いやすい円弧をベジェで追加します（Add Boundary Curve、Shape=Arc）。Radius・Angle（180 で半円）・Segments（角度が大きいときに増やす）を調整パネルで変えられます。AUTO ハンドルの近似ではなく、厳密な円弧の形になります |
| **Coons** | 選んだ 3〜4 本のカーブ（境界）で囲まれた面を張ります。カーブの向きや順番はばらばらで構いません |
| **Loft** | 2 本以上の断面カーブを順に通る面を張ります |
| **Curve Network** | 縦横に交差するカーブの網から、区画ごとに面を張り、内側の継ぎ目を G2 でつなぎます（詳しくは 5.1.1） |
| **＋（Add Curve Grid）** | 見本のカーブの網を出します。横・縦の本数、大きさ、膨らみ、はみ出しを調整できます |
| **Network Check** | Curve Network がカーブをどう見ているかを、編集に合わせて表示します（5.1.1） |
| **Move Crossing** | 網の交点をつまんで動かします（5.1.1） |
| **Fair Curves** | 選んだカーブのうねりを取ります（5.1.1） |
| **Gap Tolerance** | カーブの端どうし・辺どうしを「くっついている」とみなす距離（全体の大きさに対する割合） |
| **Snap Ends**（磁石ボタン） | 選んだカーブの近い端点どうしをくっつけます |
| **Regenerate** | アクティブな面をレシピから作り直します |
| **Fit Settings** | カーブから面を作るときの次数・読み取りの細かさ・表示の細かさ |

#### 5.1.1 Curve Network のカーブの置き方
**ルール**
1. カーブを2方向に分けて描く（横方向を何本か、縦方向を何本か。最低2本×2本）
2. 横のカーブはどれも、縦のカーブ全部と交差させる
3. 同じ方向どうしは交差させない
4. 外周のカーブより外にはみ出した部分は、自動で切り捨てられる
5. 高さはそろっていなくてよい。上から見て交差していれば、途中で出会うように自動で曲げられる
6. 1つのカーブオブジェクトに複数のスプラインがあると、最初の1本しか使われない

**Network Check の色の意味**
| 表示 | 意味 |
|---|---|
| 青・緑のカーブ | 縦横それぞれのグループ |
| 白い印 | 見つかった交点 |
| 赤い線 | 足りない交点。2本のカーブが一番近づく所を結んでいます |
| 赤い印 | 同じ方向どうしの交差 |
| 灰色のカーブ | どこにも交わらないカーブ |
| オレンジのカーブ | 交わる順番が絡んでいるカーブ |

パネルには要約（例：「4 x 3 curves, 12 crossings: ready」）と、問題がある場合はその内容が出ます。

**Move Crossing**（ベジェカーブのみ）：交点をドラッグすると、そこを通る縦横2本のカーブが一緒に付いてきます。同じカーブのほかの交点は動きません。制御点はハンドルごと動くので、カーブは滑らかなままです。

**Fair Curves**（ベジェカーブのみ）：選んだカーブのうねりを取ります。端点・端の向き・ほかのカーブとの交点は動かしません。Strength で効き具合を変えられます。

> Move Crossing と Fair Curves で動かしたカーブは、ハンドルの種類が「Aligned」になります（「Auto」のままだと、Blender がハンドルの位置を計算し直して編集が消えてしまうため）。

> 左右対称の網を作りたいときは、片側の網から面を作ってから、Group 欄の **Mirror Group** で反転してください。横方向のカーブは中心線をまたいで1本につながっている必要があるので、カーブを半分ずつミラーすると網になりません。

### 5.2 Grow & Connect（伸ばす・つなぐ）

これらの機能は、ボタンを押すと 3D ビューで辺を選ぶモードに入ります。辺にマウスを近づけると候補がオレンジに光り、名前とできあがりのプレビューが出ます。

| 機能 | 内容 |
|---|---|
| **Extend Edge** | 面の開いた辺から、G1 または G2 で面を伸ばします。ホイールで長さ。続けて別の辺をクリックすると、そこに届くまで伸ばします |
| **Bridge Edges** | 離れた2本の辺の間（または辺とカーブの間）を、滑らかな面で橋渡しします。F キーで端の組み合わせを反転 |
| **Match Edge** | アクティブな面の辺を、選んだもう1枚の面の一番近い辺に、G0/G1/G2 で合わせます（相手の面は変えません） |
| **Corner Fill** | 角で出会う2本の辺の間の、V 字の隙間を埋めます |
| **Fill Hole** | 辺（とカーブ）で囲まれた穴を埋めます。辺を順にクリックして Enter。4辺なら1枚、それ以外は中心点で分けた複数の面で埋めます。輪郭に角のない穴（筒の端など）は自動でドーム状（Radial）になります。**G0 にすると周りの傾きを使わないので、縁が平面なら真っ平らなフタになります** |
| **Fillet** | ぴったり接して折れている継ぎ目の角を、指定した半径で丸めます（5.2.1） |
| **Flange** | 開いた辺をクリックすると、その辺から壁（縁の折り返し）を立ち上げ、折れ目を Fillet で丸めます。ドア・ボンネットの縁、ホイールアーチの縁取りなどに。「最後の操作を調整」で Length（壁の深さ）・Angle（0 で真っ直ぐ延長、90 で直角、180 で折り返し）・Radius（0 で丸めない）・Flip（表側へ折る）を変えます。壁は元の面に連動し、丸めた折れ目の半径は Fillet と同じく後から変えられます |
| **Split Patch** | 面をクリックした位置の等パラメータ線で2枚に分けます。形は変わらず、境目は G2。D キーで切る向き、S キーで区間の境目への吸着 |
| **Offset Surface** | 選んだ面を法線方向に一定距離ずらしたコピーを作ります（板厚・内側の面）。元の面に連動します |

共通の操作：ホイール＝長さや Tension（両側の面の向きをどれだけ引き継ぐか）、C キー＝G0/G1/G2 の切り替え、中ボタン＝視点の回転、Esc／右クリック＝やめる。作った後は、左下の「最後の操作を調整」パネルで値を変えられます。

#### 5.2.1 Fillet（角の丸め）
1. Fillet を押すと、丸められる継ぎ目（2枚の辺がぴったり重なっている所）が表示されます
2. 丸めたい継ぎ目を順にクリック（もう一度クリックで外す）。選んでいる間もホイールでズームできます
3. Enter（または Space）で半径の調整へ。ホイールで半径、C で G1/G2、V でコーナーパッチのオン／オフ、Backspace で選び直し
4. クリックか Enter で確定

- 両側の面は、半径から決まる距離だけ切り詰められ、その間が丸いつなぎ面でつながります
- 複数の継ぎ目をまとめて丸めたとき、フィレット同士が出会う角（箱の角を3辺とも丸めた所など）の穴は、**コーナーパッチ** で自動的に埋められます
- **後から半径を変えられます**：つなぎ面を選ぶとオレンジの矢印が出るので、ドラッグします。切り詰めた面・つなぎ面・コーナーがまとめて作り直されます
- 切り詰めた面は、切り詰める前の作り方を覚えています。元にした面が動いたときは、切り詰めからやり直されます

**丸める継ぎ目の作り方**：2枚の面の辺を Match Edge（G0）で合わせると、折れた継ぎ目ができます。うまくいかないときは「8. 困ったとき」を見てください。

### 5.3 Group（まとめて扱う）

| 機能 | 内容 |
|---|---|
| **Live Update** | オンの間、元の面やカーブを動かすと、それに依存する面が自動で作り直されます |
| **Linked Edit**（＋ Falloff） | オンにすると、面を編集したとき周りの面も付いてきます。辺を共有していた面は、元の G0/G1/G2 のままつなぎ直されます。Falloff は影響が届く範囲（編集した面の大きさに対する倍率） |
| **Edge Chain** | 開いた辺をクリックすると、端でつながって同じ向きに続く辺がまとめて1本のカーブになります。そのカーブを編集すると、並んだ面の端がまとめて付いてきます |
| **Merge** | 縦横の格子状に並んだ面を、1枚の面に作り直します（近似。誤差が表示されます）。Detail で制御点の多さを調整 |
| **Select / Regenerate** | つながっている面をまとめて選ぶ ／ まとめて作り直す |
| **Mirror Group** | 選んだ面のグループを対称面（標準は X=0）で反転コピーし、元の面と連動させます。対称面にかかる辺は、左右が G2 でつながるように整えられます |
| **Cage**（Add / Apply / ✕） | 面のグループをラティスで囲み、ラティスを編集して大きく変形します。Apply で面に反映し、継ぎ目を G2 に戻します。✕ で取り消し |

### 5.4 Shape（面の内側を整える）

| 機能 | 内容 |
|---|---|
| **Soft Pull** | 面をつかんでドラッグし、周りをなめらかに引っぱります（5.4.1） |
| **Control Mesh** ／ **Done** | 面の制御点をメッシュとして出し、編集モードの G/R/S で動かせるようにします。固定された点は動かしても元に戻ります。Done で制御メッシュを消します |
| **Fair** | 面の内側をならしてうねりを取ります。固定された点と外周は動かしません |
| **Refine** | 形を変えずに制御点を増やします（細かく直したいとき） |

#### 5.4.1 Soft Pull
面にマウスを近づけると、影響する範囲が表示されます。ドラッグすると引っぱられ、Enter を押すまで何度でも引けます。

**起点（L キーで切り替え）**
| 起点 | 内容 | ホイール |
|---|---|---|
| 面上の点 | つかんだ点のまわりを球状の範囲で引く | 範囲の半径 |
| 線 | つかんだ点を通る等パラメータ線ごと、帯状の範囲で引く。D で縦横、T で両端を細らせる。外周の近くでは開いた辺に吸着 | 帯の幅 |
| 制御点 | 一番近い制御点をつかんで引く。動く制御点に印が出る | U 方向の行数（Shift＋ホイールで V 方向） |

**そのほかのキー**
| キー | 内容 |
|---|---|
| F | 減衰の形：Smooth → Sphere → Linear → Sharp → Constant（Constant は範囲内をまとめて平行移動） |
| N / X / Y / Z / V | 動かす方向：面の法線 / その軸 / 画面平面 |
| Ctrl+Z | 直前の1回を戻す |
| Enter / Space | 確定して終わる |
| Esc | すべて取り消して終わる |
| 右クリック | ドラッグ中の1回だけ取り消す |

継ぎ目で固定された点は動かないので、継ぎ目の G0/G1/G2 は保たれます。

### 5.5 Inspect（確かめる）

| 機能 | 内容 |
|---|---|
| **Zebra** | 表示中の全部の面に縞模様を映します。Stripes で縞の数、軸を選べます。オンの間は新しい面にも自動で付きます |
| **Seam Colors** | 面どうしの継ぎ目を、G2＝緑、G1＝黄、G0＝赤、離れている＝紫で表示します。編集に合わせて更新されます |
| **Curvature Comb** | 面の等パラメータ線とカーブに、曲率の「櫛」を出します。歯は曲がりの外側に伸び、長いほど強く曲がっています。歯の先を結ぶ線（包絡線）が滑らかなら曲率も滑らかです。継ぎ目やカーブの制御点で段差があれば、そこは G2 になっていません。Scale・本数・方向（U/V/両方）を調整できます |
| **Curvature Map** | 面を曲率で色分けします。Gaussian：赤＝ドーム状、緑＝平ら・円筒状、青＝鞍型。Mean：法線の向きに曲がると赤 |
| **Control Points** | 制御点を、継ぎ目で固定された点（オレンジ）と自由な点（水色）に色分けして表示します |
| **Panel Gap** | パネルの継ぎ目（向かい合う別々の面の辺）の隙間を測ります。隙間を横切る短い線が、目標値（Target）から許容（Tolerance）以内なら緑、外れていればオレンジで表示されます。一覧には継ぎ目ごとの最小・最大・平均の隙間と、段差（一方が他方より出っ張っている量）が出ます。Search より離れた辺は継ぎ目とみなしません（0 で全体の大きさの5%）。つなぎ目でぴったり接している辺は対象外です |
| **Check Continuity** | 選んだ面どうしの継ぎ目について、隙間・角度・曲率の差と、対応する辺の名前を一覧にします |

### 5.6 Output（出力する）

| 機能 | 内容 |
|---|---|
| **Mesh Resolution** | 一番長い辺の分割数。ほかの面は、同じくらいの細かさになるよう大きさに合わせて分割されます |
| **To Mesh** | 選んだ面を1つのメッシュに溶接します（Weld をオフにすると面ごとに別のメッシュ）。辺を共有する面どうしは分割数がそろい、継ぎ目は割れません |

### 5.7 矢印（ギズモ）で後から調整する
アドオンで作った面をアクティブにすると、3D ビューにオレンジの矢印が出るものがあります。ドラッグすると値が変わり、つながった面も Live Update で付いてきます。離すと Undo 1回分になります。

| 面 | 矢印の場所 | 変わる値 |
|---|---|---|
| Extend Edge で作った面 | 元の辺の中央 | 伸ばす長さ |
| Offset Surface で作った面 | 元の面の中央（法線方向） | 距離（反対側にも引ける） |
| Fillet のつなぎ面 | 元の角から、つなぎ面の中央へ | 半径 |

手で直した面には矢印は出ません（作り直すと手の修正が消えてしまうため）。

## 7. 仕上がりの確かめ方

1. **Seam Colors** で、全部の継ぎ目が狙いどおりの色（車の外板なら緑＝G2）か見る
2. **Zebra** で縞模様を映し、継ぎ目で縞が折れたり太さが急に変わったりしていないか見る
3. **Curvature Comb** で、包絡線に段差やうねりがないか見る。カーブの段階で見ておくと、面にしてから直すより楽です
4. 気になる継ぎ目は、2枚を選んで **Check Continuity** で数値を確かめる
5. 面の内側のうねりは **Fair**、局所的な形は **Soft Pull** で整える

## 8. 困ったとき

| 表示・症状 | 原因と対処 |
|---|---|
| no edge lies close to the reference patch | Match Edge で、2枚の辺が離れすぎています。面を近づけるか、Create 欄の Gap Tolerance を一時的に上げてください |
| Fillet で継ぎ目が出てこない／No coincident edges between visible patches | 丸めるには、2枚の辺がぴったり重なっている必要があります。先に Match Edge（G0）で辺を合わせてください |
| the radius is too large | 半径が大きすぎて、面の幅に収まりません。半径を小さくしてください |
| 半径の矢印が出ない／edited by hand since the fillet | 切り詰めた面かつなぎ面を手で動かしています。Regenerate でレシピの形に戻すと、再び変えられます |
| every curve must cross every curve of the other direction | Curve Network で交点が足りません。Network Check をオンにすると、足りない所が赤い線で示されます |
| curves of the same direction cross each other | 同じ方向のカーブどうしが交差しています。Network Check で赤い印の所を直してください |
| boundary loop is not closed | Coons で、カーブの端どうしが離れています。Snap Ends で端をくっつけるか、Gap Tolerance を上げてください。Blender 標準の Nurbs Path を境界に使っている場合は、既定で Endpoint がオフなので角に隙間ができていることがあります（Create 欄の Line / Arc を使うとこの問題を避けられます） |
| Live Update で付いてこない面がある | その面は「手で直した面」です。パネル上部に「not updated (hand edited)」と表示されます。Regenerate すると付いてくるようになります（手の修正は消えます） |
| To Mesh で小さい面が粗い | Mesh Resolution は一番長い辺の分割数です。値を上げてください |
| 面の向き（表裏）が逆に見える | ビューポートの Overlays → Face Orientation で確認できます。表裏は、つないだ相手の面に合わせて決まります |

## 9. 制約と既知の課題

- 窓・ライトなどの開口部の切り抜きは、まだできません
- Fillet の切り詰め量は、継ぎ目全体で一定です。継ぎ目に沿って面の角度が大きく変わる形では、丸みの大きさが場所によって少しずれます
- 3本の辺のうち2本だけを丸めた角では、つなぎ面の端が斜めになり、きれいなコーナーにはなりません
- 4辺以外の Fill Hole とコーナーパッチは、中心点の付近で G2 がわずかに崩れます（最大1°程度）
- Corner Fill の頂点は近似になります
- To Mesh で、長い辺に短い面が2枚接する所は、四角形でなく5角形以上の面になります
- Curvature Comb / Map は、面を1枚動かすたびに表示中の全部の面を計算し直します。面が非常に多いと重くなることがあります
- Move Crossing と Fair Curves はベジェカーブのみ対応です
- Split Patch で切った面は、作り方の記録を持たない「固定された面」になります

## 10. 用語集

| 用語 | 意味 |
|---|---|
| パッチ | アドオンが扱う NURBS の面1枚 |
| 制御点 | 面やカーブの形を決める点。面そのものの上にあるとは限らない |
| 等パラメータ線 | 面の U か V の値を一定にしてできる線。面の上の「縦の線・横の線」 |
| 継ぎ目 | 2枚の面が接している辺 |
| 継続性（G0/G1/G2） | 継ぎ目でのつながりの滑らかさ（3章） |
| 曲率 | 曲がり具合。半径 R の円の曲率は 1/R |
| レシピ | 面が「何から、どう作られたか」の記録 |
| Live Update | 元の面やカーブが変わったとき、依存する面を自動で作り直す仕組み |
| 手で直した面 | レシピで作った後に手で編集された面。自動では上書きされない |
| 固定された点 | 継ぎ目の滑らかさを守るため、編集で動かさない制御点 |
| Tension | つなぐ面が、両側の面の向きをどれだけ引き継ぐかの強さ |
| つなぎ面（Fillet） | Fillet で、切り詰めた2枚の面の間に入る丸い面 |
| コーナーパッチ | フィレット同士が出会う角の穴を埋める面 |
| 包絡線 | 曲率の櫛の歯の先を結んだ線 |
