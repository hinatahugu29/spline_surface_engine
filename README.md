# Spline Surface

車のボディのような滑らかな曲面を、NURBS に慣れていなくても作れるようにする Blender 5.x 用アドオンです。
面は Blender の NURBS サーフェスで作り、最後にメッシュにして使います。

## インストール
1. `dist/` にある最新の `spline_surface-x.y.z.zip` を用意する
2. Blender の「編集 → プリファレンス → アドオン」の右上メニューから「ディスクからインストール」で ZIP を選ぶ
3. 3D ビューのサイドバー（N キー）に **Spline Surface** タブが出ます

## 基本の流れ
1. **作る**：Add Patch で面を出すか、カーブを3〜4本描いて Coons、断面カーブを並べて Loft、縦横に交差するカーブの網から Curve Network
2. **伸ばす・つなぐ**：Extend Edge で辺から伸ばし、Corner Fill・Fill Hole・Bridge Edges で隙間を埋める
3. **確認する**：Seam Colors（G2 緑・G1 黄・G0 赤）と Zebra（縞模様）でつなぎ目の滑らかさを見る
4. **まとめて直す**：元の面を動かせば Live Update で全体が付いてくる。大きな変形は Cage、左右対称は Mirror Group
5. **出力する**：To Mesh で1つのメッシュに溶接

## パネル
| 欄 | 内容 |
|---|---|
| Create | Add Patch、Coons、Loft、Curve Network（＋ボタンで見本のカーブの網）、Snap Ends（カーブの端をくっつける）、Regenerate、Fit Settings |
| Grow & Connect | Extend Edge、Bridge Edges、Match Edge、Corner Fill、Fill Hole、Split Patch、Offset Surface |
| Group | Live Update、Linked Edit（＋Falloff）、Edge Chain、Merge、Select / Regenerate、Mirror Group、Cage（Add / Apply / ✕） |
| Inspect | Zebra（表示中の全部の面に一括、On の間は新しい面にも自動）、Seam Colors（つなぎ目を継続性で色分け）、Soft Pull（面上の点をドラッグして形を整える。つなぎ目で固定された点は動かないので G0/G1/G2 を保つ。ホイール＝範囲、N＝法線方向、X/Y/Z＝その軸方向、V＝画面平面）、Control Mesh（制御点をメッシュにして編集モードで G/R/S。固定された点は元に戻り、Done で消す）、Control Points（制御点を、つなぎ目で固定された点＝オレンジ／自由に動かせる内側＝水色で表示）、Check Continuity（結果の一覧） |
| Output | Mesh Resolution、To Mesh |

## クリックで選ぶツールの操作
Extend Edge・Corner Fill・Bridge Edges・Fill Hole・Split Patch は、押すと 3D ビューで選ぶモードに入ります。

| 操作 | 内容 |
|---|---|
| マウスを近づける | 候補がオレンジに光り、名前とプレビューが出る |
| 左クリック | 選ぶ（選び済みをもう一度クリックすると外す） |
| ホイール | Extend は長さ、ほかは Tension（両側の面の向きを引き継ぐ強さ） |
| C | 継続性の切り替え（G0 / G1 / G2） |
| F | Bridge Edges：端の組み合わせを反転 |
| D / S | Split Patch：切る向き／区間の境目への吸着 |
| Enter / Space | Fill Hole：選んだ辺で埋める |
| 中ボタン | 視点の回転（モード中も使える） |
| Esc / 右クリック | やめる |

作成後は、左下の「最後の操作を調整」パネルで値を変えられます。

## 継続性の目安
- **G0**：位置だけつながる（折れ目が見える）
- **G1**：向きまでそろう（縞模様が折れずにつながる）
- **G2**：曲がり具合までそろう（縞模様の太さも途切れない。車の外板の目標）

## Curve Network のカーブの置き方
まずは Curve Network の横の **＋**（Add Curve Grid）で見本の網を出し、点を動かして形を変えるのが一番簡単です。

自分で描く場合のルール：
1. **2方向に分けて描く**：横方向（例：X 方向に走るカーブ）を何本か、縦方向（Y 方向）を何本か。最低 2本×2本
2. **全部交差させる**：横のカーブはどれも、縦のカーブ全部と交差させる。途中で終わって届かない線があると作れない
3. **同じ方向どうしは交差させない**：横どうし・縦どうしが交わると作れない
4. **外周は少しはみ出させて良い**：外側のカーブより外に出た部分は自動で切り捨てる
5. **高さは揃っていなくて良い**：上から見て交差していれば、高さが違っても中間で出会うように自動で曲げる（網全体の向きから「上」を判断）
6. **1本のカーブは1つのスプライン**：1つのオブジェクトに複数のスプラインがあると最初の1本しか使わない

ベジェなら上面図で横線・縦線を引き、側面図や G Z で高さの起伏を付けるのが手早いです。

## 面が増えてきたら（v0.21）
- **Linked Edit**（Group パネルのチェック）：オンにすると、面を編集（編集モードで制御点を動かして Tab で戻る、または移動）したとき、周りの面も付いてきます。辺を共有していた面は、元の G0/G1/G2 のままつなぎ直されます。Falloff で影響が届く範囲（編集した面の大きさに対する倍率）を決めます
  - 付いてくるのは「編集中（アクティブ）の面」から周りへです。周りの面は「手で直した面」として扱われます
  - 元の面から作られた面（Extend など）は、動かすのではなく Live Update で作り直されます
- **Edge Chain**：開いた辺をクリックすると、端でつながって同じ向きに続く辺がまとめて選ばれ、1本の NURBS カーブ（EdgeChain）になります。このカーブを編集して Tab で戻ると、並んだ面の端がまとめて付いてきます。カーブはそのまま残しておけば何度でも使えます
- **Merge**：選んだ面（縦横に並んだ格子状のもの）を1枚の面に作り直します。元の面は隠されます（調整パネルで削除も可）。Detail で制御点の多さを調整。近似なので、誤差（%）が報告されます。仕上げ向けで、元の面から作られていた面は元の面に連動したままです

## 知っておくと良いこと
- 手で編集した面は「手で直した」と記録され、Regenerate や Live Update で上書きされないようにしています（Regenerate を押した場合は警告が出て、Ctrl+Z で戻せます）
- 対応する面：Endpoint がオン、Cyclic なし、制御点の Weight がすべて 1
- Corner Fill の頂点と、4辺以外の Fill Hole の中心付近は、わずかに近似になります
- Fill Hole の Layout：輪郭に「角」がない穴（筒の端のフタなど）は自動で Radial（中心に集まるドーム状の面）になります。Grid / Radial は調整パネルで切り替え可。Radial の境目は G1（折れなし）で、曲率までは揃いきらないことがあります
- Split Patch で切った面は、作り方の記録を持たない「固定された面」になります
- Offset Surface は近似（標準で誤差は距離の1%程度以下）。元の面に連動します

## 試してほしいこと（v0.16 の調整用チェックリスト）
気になった点があれば、番号と一緒に教えてください。

1. Add Patch → Extend Edge を何回か：辺の選びやすさ、ラベルの見やすさ、ホイールでの長さ調整
2. Corner Fill / Bridge Edges / Fill Hole：2本目以降の選び方、プレビューの分かりやすさ
3. 元の面を G で動かす：Live Update の追従と重さ（面が10枚を超えるくらいで）
4. Mirror Group → 片側を編集：反対側の追従、中心線のゼブラ
5. Cage：Add → Lattice 編集 → Apply の流れ
6. Split Patch：切る位置の分かりやすさ、D / S キー
7. To Mesh：溶接結果、シェーディング
8. パネル全体：並び順、名前、足りない／要らないボタン
